What the agent did

    Not a guess. A path.

    An LLM alone can only free-associate. Every stop here is a real Qloo entity, chosen because it scores high affinity with the stop before and the stop after — computed across millions of real taste signals.

    Fair to both people.

    The bridge is picked by maximising the weaker side's affinity, so the meeting point is somewhere both people genuinely lean in — not one person's taste with a ribbon on it.

    A tool for any agent.

    The pathfinder is also an MCP server. Plug it into Claude or any agent and it can find common ground between people.
